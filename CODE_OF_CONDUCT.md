# Code of Conduct

OpenDM is a small, friendly project. Everyone who takes part (in issues, pull requests,
discussions and anywhere else the project is represented) is expected to:

- be respectful and patient, especially with newcomers and people whose first language is
  not English;
- discuss ideas, not people, and accept that a maintainer may decline a change;
- give and take feedback constructively;
- respect privacy: never post other people's personal data, and remove secrets (cookies,
  tokens) from logs before sharing them.

Not acceptable: harassment, insults, discriminatory jokes or language, sexual content,
threats, publishing others' private information, and requests to help break DRM or the law.

## Enforcement

Report problems privately to the maintainer, Indrajit Gupta, through the contact on the
[GitHub profile](https://github.com/Indrajit147) or a private security report
([SECURITY.md](docs/SECURITY.md)). Reports are handled confidentially. The maintainer may
edit or remove comments, close issues, and block people who break these rules, starting
with a warning except for serious cases.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1.
